# Pokémon Portfolio🎮

A playful, Pokémon-themed personal portfolio for **Vamshi Mandre**. You land on a grassy field with a floating Poké Ball — tap it to open the animation and enter the portfolio.

🔗 **Live Demo:** https://vamshimandre.netlify.app

## What's Inside

| File           | What it is                                     |
| -------------- | ---------------------------------------------- |
| `index.html`   | Pokémon-themed landing page with the Poké Ball |
| `details.html` | Personal profile and portfolio page            |
| `styles.css`   | Website styling and responsive design          |
| `script.js`    | Animations and interactive behavior            |
| `home.mp4`     | Poké Ball opening animation                    |
| `poster.png`   | Landing animation poster                       |
| `avatar.png`   | Portfolio avatar                               |
| `grass.jpg`    | Grass background                               |
| `favicon.png`  | Browser tab icon                               |
